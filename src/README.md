# Predictive Maintenance Platform

## Overview
This project predicts the Remaining Useful Life (RUL) of aircraft turbofan engines using the NASA CMAPSS dataset. It demonstrates an end-to-end machine learning pipeline including data preprocessing, feature engineering, model training, evaluation, and prediction.

## Features
- Data preprocessing
- Feature engineering
- Machine learning models
- Remaining Useful Life (RUL) prediction
- Model evaluation
- Data visualization

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow
- Matplotlib
- Google Colab
